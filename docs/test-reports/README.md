# Test reports

One report per flown test plan. Naming: `TR-NNN_short-description.md`, same number as the test plan.

## Template

```markdown
# TR-NNN: <title>

| | |
|---|---|
| Test plan | ../test-plans/TP-NNN_... |
| Date flown | |
| Parameter set | params/<file> |
| Logs | logs/<file>.ulg or release attachment |
| Conditions | temperature, wind |

## Summary
Two or three sentences: what was tested, main result.

## Results
Measured values, plots (analysis/<script>.py).

## Deviations from the plan

## Findings

## Decision / next step
```
